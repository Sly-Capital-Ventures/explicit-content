# The Brain

The shared knowledge base for content on **explicitsarms.com**. Both the authoring AI and the automated review agent read these files, so what's written matches what's enforced. Read them in this order:

1. **`compliance.md`** — the no-claims ruleset. **Non-negotiable, read first.** It's what the review agent hard-blocks against.
2. **`product-catalog.md`** — the only products you may reference (real names + slugs). Never invent one. Marks which compounds are out-of-scope.
3. **`article-format.md`** — the required article structure + frontmatter.
4. **`seo-conventions.md`** — titles, meta, slugs, internal linking, and what to leave to the build (schema, RSS).
5. **`brand-voice.md`** — the tone: factual spec-sheet, never persuasion toward use.

## The one rule (the whole thing in a sentence)
Describe the **compound and the product** — never its **effect, benefit, or use in a body**. Peptides only; SARMs / SERMs / AIs / GLP are excluded unless explicitly approved.

## How content ships
Draft in the SEO dash (**seo.explicitsarms.com**) *or* have your AI open a Pull Request directly. Either way: the **compliance agent** checks it, an **Explicit reviewer merges** it, and the build publishes it + updates `feed.xml`. Nothing goes live without that review — that's the point.
